## Deskripsi
Tugas ini melakukan eksplorasi data menggunakan dataset bawaan R, yaitu `airquality`.
Eksplorasi dilakukan pada variabel `Wind` dengan beberapa visualisasi sesuai materi Eksplorasi Data.

## Analisis yang dilakukan
1. Histogram variabel `Wind` dengan kurva density
2. Boxplot variabel `Wind`
3. Stem-and-leaf plot variabel `Wind`
4. Scatter plot antara `Wind` dan `Ozone`

## Dataset
Dataset yang digunakan adalah `airquality`, yaitu dataset bawaan R yang berisi data kualitas udara di New York pada tahun 1973.
